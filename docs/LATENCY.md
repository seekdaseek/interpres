# transcription_mode: balanced against min_latency

Generated by `scripts/latency-ab.ts report` from two in-process A/Bs, each session set up exactly as the page sets up its server. "balanced" sends no `transcription_mode`: the API's default, and what interpres sent until round H. "min_latency" adds `input.transcription_mode: "min_latency"` to every input update, which is what interpres now sends. End of turn runs from the clip's last voiced sample to the API's `input.speech.stopped`. Voice to voice is measured the `e2e-audio` way, from the clip's last chunk sent to the first `reply.audio`. A turn splits when the utterance becomes more than one `transcript.user`, or a reply begins before the clip's last voiced sample.
